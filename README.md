# My-Bharat-Green-Skills-and-Tribal-Empowerment-Network.
MY Bharat prototype for mining zones like Balaghat. Links Baiga tribal artisans with youth to turn bamboo/paddy waste into eco-furniture. Features geo-tagged plantations tracked via ISRO Bhuvan GIS &amp; AI verification to award Green Credits, granting apprenticeship priority with industries like MOIL &amp; HCL under Viksit Bharat 2047.
